# 介绍

Mihomo 是在无图形化 linux 系统上比较好用的 **VPN 工具**。本仓库意在提供一个可复用的文档，使得**只需告诉 agent 一个命令，它即可自主在远程服务器上安装并配置好 mihomo**。

# 使用命令

```text
请完整阅读 mihomo.md，按文档完成安装与配置。

目标机器：<SSH 别名或当前机器>
订阅链接：<订阅链接>
代理启用方式：<所有终端启用 / 终端中手动启用>
节点要求：<地区或具体节点>
安装位置：<指定绝对目录>
```

# 测试效果

经本人测试，对 gpt-6.1-sol high fast 输入以上命令，**六分钟**在一台远程服务器上安装并配置好了 mihomo 的节点。
